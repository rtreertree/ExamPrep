# Exam Prep — visual concept prompts

Initial layout concepts generated using the built-in image tool for the Graphite / Volt design handoff. The [minimal material revision](minimal-concept-prompts.md) and [current design contract](../design.md) govern the finish. These original prompts remain a record of the layout references, not an instruction to suppress the revised subtle gradient/frosting.

Each screen prompt below was sent after the shared brief, unchanged. Generation used an opaque background. The corresponding PNGs are in [references](references/).

## Shared brief

Use case: ui-mockup. Create a production-quality full-screen desktop application concept for Exam Prep, a private university exam and flashcard practice application. This is a design reference only, not a marketing site. Native image should be 1536x1024 landscape or a similar large readable landscape size. The creative direction is GRAPHITE / VOLT: an editorial study studio at night, calm charcoal backgrounds #111315, slightly raised graphite #1A1D21 and #20242A, warm white type #F5F3EC, secondary #BAC0C8, muted #949CA8, hairline separators #30343D, a single acid lime accent #D9F77E with very dark label #151A0A. Excellent warm neo-grotesk typography like Instrument Sans, generous whitespace, clear type scale, tabular small numbers. No purple/blue gradients, rainbow glow, illustration, planets, glassmorphism, fake charts/stats, bento grids, huge pill labels, AI sparkle symbols, promotional hero, or badge above title. Give it taste, editorial precision, distinctive composition and practical reusable components. Corners restrained: 8px controls and 12px panels. Fine outline icons 18px / 1.75px stroke, only when functional. One quiet lime vertical marker is a signature motif. Buttons primary lime solid, secondary charcoal with visible outline. All text and controls must look implementable as actual code-native UI. No logos except the simple text wordmark "Exam Prep". No browser chrome. Preserve sufficient contrast, label sizes, one clear focal task. Entire screen must be visible with clean margins. Every sample is illustrative demo data, not user statistics.

## library

Top wordmark "Exam Prep"; navigation "Library" active with narrow lime line and "History"; bottom "Account" and small sign-out icon. Below heading use thin underline tabs "All", "Exams", "Flashcards", selected "All" underlined lime, no search. The library is four generous horizontal rows with fine dividers, not a grid: narrow monospaced row numbers 01,02,03,04; titles "Calculus II — Integrals", "Linear Algebra — Eigenvalues", "Organic Chemistry — Reactions", "Derivative rules"; second text "Exam · 12 questions", "Exam · 16 questions", "Flashcards · 24 cards", "Flashcards · 18 cards". Right side per row: "Practice" action and ellipsis menu. First row hover state is subtly lighter with a quiet lime edge and a slightly forward arrow; it must remain a row. Bottom open empty space rather than dashboard widgets. One low-contrast lime light seam along the topmost edge of main area, like a brief interaction trace, no ambient circles. Ensure refined whitespace and clearly readable content.

## practice

SCREEN: Exam practice view, complete primary application screen with excellent question readability. Focus layout replaces large sidebar with a small back control "Library" at top left and wordmark "Exam Prep"; centered set title "Calculus practice"; top right honest status "Saved". Thin progress track below header with lime segment and muted rest. Main max 800px centered, generous breathing room. Left margin question ordinal "01" in mono, with "of 03" smaller. Main shows small plain label "Single choice" then large readable question "Evaluate the integral." Underneath a correctly rendered large mathematical integral from 0 to 1 of x squared dx. Four options? EXACTLY THREE vertically stacked wide options as reusable radio rows: A "1/2", B "1/3", C "1". Option B is selected with visible radio dot, lime keyline and very subtle lime tint; selected must not communicate correctness before submission. Options are 64px high, radius8, consistent. Body text remains warm white; mathematical notation is clear. Bottom study footer is anchored with "Previous" subdued on left, "Question 1 of 3" middle, "Next" primary lime on right and secondary "Submit exam" beside it. Footer stays separate, no countdown or score before submission. No distracting art, no text animation rendered in still. A three-button question navigation list can be in a quiet right margin and must label 1 answered,2 unanswered,3 unanswered using outline/dot rather than green correctness. Do not add unrelated navigation or analytics.

## editor

SCREEN: Content editor, full desktop app. Same 216px sidebar and wordmark with Library active, History, Account bottom. Main top left back link "Library"; title "Calculus practice"; top right secondary "Export" and primary lime "Save". Under title small save label "Draft saved on this device" in muted text, distinct from database Save. A precise three-region workspace, not nested decorative cards: left item rail 192px, middle editing column 440px, right preview column remaining width. Workspace separated by vertical fine lines. Left rail heading "Questions", three reusable rows "01 Integral", "02 Power rule", "03 Constant"; second selected with lime vertical marker and lifted graphite fill; bottom "Add question". Middle heading "Written answer"; fields with true labels "Question", "Reference answer"; multiline field includes "Differentiate x^3 using the power rule." The reference field contains a short Markdown/math source string. Lower a compact rubric editor labelled "Marking rubric" with reusable rows: "Power rule and substitution" maximum "2", "Working and final answer" maximum "3"; action "Add criterion"; show derived "5 points total". Right heading "Preview"; show the exact readable question and rendered reference formula d/dx x^3 = 3x², then two clean rubric rows with matching descriptions and point maxima. Preview must be visibly separate from inputs and not look like student answer grading. Restrained radius8 fields with medium-contrast boundaries. Keep all three regions and toolbar readable. No floating extra UI, no AI features, no fake metrics. Strong visual hierarchy, precise reusable form and list components.

## flashcards

SCREEN: Flashcard practice, complete desktop application in same dark visual family as previous app screens. Focus shell with "Library" back control at left, "Exam Prep" wordmark, centered title "Derivative rules", "Saved" at right. Slim lime progress track and quiet ordinal "Card 1 of 2". Central single purposeful card frame, 760px wide, around460px high, graphite #1A1D21 with a very thin #686E7C border and radius12, casting restrained dark depth. This is the ANSWER REVEALED state, not an editor. Top left within card a small functional label "Answer"; readable cue "The product rule"; large perfectly rendered mathematical formula d/dx(fg) = f′g + fg′; below one short explanation "Differentiate each factor in turn." No displayed count in card. The upper right card corner has a tiny two-sided card icon, not decorative sparkle. Bottom below card rating actions: outlined "Review again" on left and solid lime "Known" on right, equally wide,44px high. These buttons show only after reveal. At bottom separated from rating actions a quiet secondary "Finish session". Footer label "Your ratings are saved as you go." Use intentional large breathing room. A tiny lime edge trace on the card suggests flip motion; no duplicate cards, no particle effects or giant background artwork. The overall design feels a contemporary editorial study object with tactile but restrained three-dimensional depth, easy to build using reusable shared buttons and the same headers as exam practice. No timers, streaks, fake scores, badges, or unrelated controls.
